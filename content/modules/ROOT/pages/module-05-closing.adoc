== Key Takeaways

*AgentOps extends traditional DevOps observability to handle the unique challenges of AI applications:*

* *Logs* ({ocp-short} Console + `oc logs`) capture what happened and when -- essential for debugging failures and auditing events. {ocp-short} captures all container output automatically with no code changes required.

* *Traces* (MLflow) capture why things happened -- the full execution path from user question through LLM calls, tool invocations, and response generation. MLflow autolog enables this with a single line of code.

* *Metrics* ({ocp-short} Observe + NVIDIA DCGM) capture how much and how fast -- GPU utilisation, memory pressure, pod resource consumption. These metrics help you right-size deployments and detect performance bottlenecks.

Together, these three pillars give you *complete visibility* into your AI application:

[cols="1,2,2",options="header"]
|===
| Pillar | Answers | Tool

| Logs
| _What exactly happened?_
| {ocp-short} Console + `oc logs`

| Traces
| _Why did it happen? What was the flow?_
| MLflow Tracing

| Metrics
| _How much? How fast? How loaded?_
| {ocp-short} Observe + NVIDIA DCGM
|===
