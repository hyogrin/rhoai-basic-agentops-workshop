== 핵심 요점

*AgentOps는 AI 애플리케이션의 고유한 과제를 처리하기 위해 전통적인 DevOps 관측성을 확장합니다:*

* *로그* ({ocp-short} Console + `oc logs`)는 무슨 일이 언제 발생했는지 캡처합니다 -- 실패 디버깅과 이벤트 감사에 필수적입니다. {ocp-short}는 코드 변경 없이 모든 컨테이너 출력을 자동으로 캡처합니다.

* *트레이스* (MLflow)는 왜 일이 발생했는지 캡처합니다 -- 사용자 질문에서 LLM 호출, 도구 실행, 응답 생성에 이르는 전체 실행 경로입니다. MLflow 오토로그는 한 줄의 코드로 이를 가능하게 합니다.

* *메트릭* ({ocp-short} Observe + NVIDIA DCGM)은 얼마나, 얼마나 빠르게를 캡처합니다 -- GPU 활용률, 메모리 압박, Pod 리소스 소비입니다. 이러한 메트릭은 배포 규모를 적정화하고 성능 병목을 감지하는 데 도움이 됩니다.

이 세 가지 축을 함께 사용하면 AI 애플리케이션에 대한 *완전한 가시성*을 확보할 수 있습니다:

[cols="1,2,2",options="header"]
|===
| 축 | 답변 | 도구

| 로그
| _정확히 무슨 일이 발생했는가?_
| {ocp-short} Console + `oc logs`

| 트레이스
| _왜 발생했는가? 흐름은 어떠했는가?_
| MLflow Tracing

| 메트릭
| _얼마나? 얼마나 빠르게? 부하는?_
| {ocp-short} Observe + NVIDIA DCGM
|===
