= Basic AgentOps on Red Hat AI

A hands-on workshop for understanding and practicing AgentOps observability on {rhoai} {rhoai-version}.

Participants learn to deploy an AI-powered application with MLflow tracing, explore application logs using LokiStack, analyze request traces in MLflow, and monitor GPU utilization and resource usage through the OpenShift Console.

Created: 2026-10-09

=== Local Development

==== Using Containers (Recommended)

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

For SELinux environments:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora:z -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

Open http://localhost:8080 in your browser.
